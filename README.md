# Smart Notes AI

A simple full-stack application that converts unstructured text into structured insights.

## 🚀 Features
- Summary generation
- Key point extraction
- Action item detection
- Clean UI

## 🛠️ Tech Stack
- React (Frontend)
- Node.js + Express (Backend)

## ⚙️ How to Run

### Backend
cd backend  
npm install  
node server.js  

### Frontend
cd frontend  
npm install  
npm start  

## 💡 Description
Built a lightweight AI-inspired system that transforms raw text into structured knowledge (summary, key points, action items). Designed to simulate knowledge management workflows.
